To retry a workflow, do the following:

1. Navigate to **Sources -> Dataflows -> \[Name of Dataflow] -> \[Failed Run]**
2. Highlight the dataflow run that failed to bring up the right rail.
3. Click on** Retry**. The retry will take the copy of the data associated with the failed run and will now apply the new mapping rules to it

![](assets/hAM7pnj6e1DMu6NFJ-mC4_retry-a-failed-dataflow.png)

>[!NOTE]
>Note that when you retry a failed dataflow a new dataflow is created and executed. It will appear at the top of the list of dataflows
