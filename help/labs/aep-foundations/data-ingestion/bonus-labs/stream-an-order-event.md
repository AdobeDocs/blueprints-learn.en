## **Prerequisites**

1. You have downloaded the [Sample Files](<././Sample Files.md>) and see the file named --> **Lab\_Single\_Order\_sample.json**
2. You have successfully completed the [Using Data Landing Zone](<./Using Data Landing Zone.md>) lab and have a valid mapping set to import

## Challenge

Perform the following set of tasks just as you did in the previous lab. 

1. Create a new account using the HTTP API source connector
2. Setup a dataflow using the new account to stream data into your own Customer Orders dataset
3. Re-use the mapping set from the [Using Data Landing Zone](<./Using Data Landing Zone.md>) lab
4. In Postman populate the **Create Order Event** with the necessary information to successfully stream in the data and attach it your previously created Customer Account record
5. Verify the Order is linked to your profile

>[!NOTE]
>Good luck and may the Adobe Experience Platform gods be with you!
