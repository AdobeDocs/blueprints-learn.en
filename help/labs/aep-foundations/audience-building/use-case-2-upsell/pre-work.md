For this Use Case there isn’t much pre work to do. We basically have two things we are looking for, 1) Usage 2) Plan.  Let's find where they are.

# Billing Data Usage

1. Create a new Audience
2. Search for "usage" in Attributes. Click on the "i" to review the description (there is none).

![](assets/fND4nWcc1E-DR5SrhiMrZ_search-f.png)



3\. Search for "usage" in Events.  Click on the "i" to review the description (there is none).

![](assets/Z87gAWit_1QQxVVAazOVE_search-f.png)

>[!CAUTION]
>Neither of these have any descriptions, so the Marketer will may make some assumptions and guess wrong. 
>
>Descriptions are important.  Without descriptions, how will the Marketer know:
>
>- Which to use?
>- Latency of data?
>- Recommended/preferred in specific use cases?
>
>By providing this information in descriptions we can better guide them.

>[!WARNING]
>Try searching for “Billing”.  Notice it doesn't show up as a Profile Attribute.  It shows up as an Event Type Card along with the the "Billing Data Usage" field.
>
>Naming conventions exist for your Marketer too.  Depending on what they search on or if they are looking/expecting this to be an Event or on Profile affects what they find and eventually use.
