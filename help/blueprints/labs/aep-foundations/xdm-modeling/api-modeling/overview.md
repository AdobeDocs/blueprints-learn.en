# API modeling

## Lab overview

Working with the Experience Platform APIs is critical to understanding how to automate and operationalize various features of the platform. Defining schemas and understanding how data is described by those schemas is one of the first things a customer will do on Adobe Experience Platform as they define their data architecture.

This lab will introduce you to the Adobe Experience Platform schema design experience utilizing only the APIs. You will learn how to create your own schemas utilizing existing XDM components, adding your own customizations in XDM and identifying and creating various identity descriptors for use with the Real-Time Customer Profile.

## Learning objectives

Be able to build a schema utilizing only the Experience Platform APIs through a variety of XDM foundational components such as:

1. Classes
1. Field Groups
1. Descriptors
   1. Identities (including Primary)
   2. Relationship
   3. Reference
