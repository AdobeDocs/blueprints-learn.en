# Learning Objectives

## Mapping Source to XDM

Get experience with translating what you put on paper and learn how to discover and map to XDM **standard** objects and fields versus create **custom** objects and fields.

What you will walk away with:

- UI knowledge of how the Experience Data Model concepts look in real-life
- Understand how objects and fields are defined in the context of **XDM field groups**
- Understand how to use the Schema UI to explore XDM standard field groups



## Building XDM via UI

Go hands on with building out the Connection 5G Customer Account schema that utilizes the schema you created in using the LID methodology

What you will walk away with:

- Basic understanding for overall schema composition UI
- Learn how to add XDM standard field groups to a schema
- Learn how to remove unnecessary fields from XDM standard field groups
- Be able to create and use custom field groups in a schema
- Learn to save often during schema development 😄
- Understand the differences between enums and suggested values



## Configuring for Profile

Learn the steps required to configure a schema for use with the Real-Time Customer Profile from identity marking to establishing relations for lookup schemas.

What you will walk away with:

- Be able to mark a field as an identity or primary identity
- Build a relationship between two schemas
- Understand the reason why to **test** the schema before enabling for Profile
- Understand the **union schema** and visually see it in action
