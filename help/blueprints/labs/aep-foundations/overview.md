# Overview

## What you will learn

1. **Relational to NoSQL Translation:**
   - Understand the architecture, modeling, and assembly of the Real-Time Customer Profile
   - Apply the LID Methodology to a fictional scenario for modeling the Real-Time Customer
1. **Experience Data Model (XDM):**
   - Learn components of XDM and their relevance to Real-Time Customer Profile behavior
   - Hands-on practice with schema building using both the UI and API
1. **Data Ingestion and Profile Creation:**
   - Differentiate between various data stores in Adobe Experience Platform
   - Learn data processing for batch and streaming sources
   - Hands-on labs to ingest data and create profiles
1. **Segmentation/Activation and Audience Building:**
   - Understand segment evaluation forms supported by Real-Time Customer Profile
   - Differentiate Hub vs. Edge profile functionalities
   - Build and activate audiences in the UI, including working with streaming destinations



## Target audience

- Solution Architects
- Enterprise Architects
- Developers
- Data Engineers
- Data Architects



## Recommended experience or familiarity

- Database concepts (create, update, delete)
- Data modeling concepts (rows, fields, keys, etc.)
- Working with REST APIs
- General understanding of Adobe Experience Platform
- Exposure to CDPs, ad-tech, CRM or other marketing technology stacks
