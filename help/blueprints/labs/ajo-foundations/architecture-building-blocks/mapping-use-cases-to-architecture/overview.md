# Mapping use cases to architecture

## Learning objectives

By the end of this lab, you will be able to:

- Apply a structured decision-making framework to evaluate real-world marketing use cases
- Identify the AJO architecture components required to support each use case
- Select the appropriate orchestration engine — Orchestrated Campaigns or Journeys — and justify your recommendation
- Explain the correct architecture decisions for all three Connection 5G use cases and articulate the signals that drove each one
