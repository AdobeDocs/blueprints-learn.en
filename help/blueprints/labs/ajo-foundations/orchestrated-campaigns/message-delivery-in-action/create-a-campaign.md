# Objective

In the next set of steps you will start with creating an Orchestrated Campaign.

# Create Campaign

1. In the left side rail, click on **Campaigns**

![Campaigns](assets/VcJhv83IcbJLFOToqA4K--20251208-061706.png)

2. Click on **Create campaign**

![Create campaign](assets/XDzXpoJVQ8UAPUFjUIKcm-20251208-042622.png)

3. Select **Orchestration - Marketing**  and click on **Confirm**

![Select Orchestration](assets/rXDETbHLsGn6XAwz5L6Xp-20251208-042621.png)

4. Provide Campaign details below and then click the **Save button** when done
   - **Name:** `OC-MDL-Campaign-Test`
   - **Description:** `OC Message Delivery Test`

![Provide Campaign details](assets/fgX-_njs7hcdMW0uQRWo3-20260114-182608.png)

5. Wait for the confirmation message before proceeding

![Settings updated](assets/y6QUWL_l822TK1o3c_PSS-20260114-182608.png)

# Recap

You created an Orchestrated Campaign with all the basic settings configured which will be used in the next set of steps.
