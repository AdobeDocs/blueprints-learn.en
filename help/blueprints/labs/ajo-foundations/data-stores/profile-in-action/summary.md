In this lab, you configured a datastream and sent a simulated web event to the Edge Network using Postman to observe how data flows through Adobe Experience Platform.

You validated that the event was processed by multiple platform services by confirming that a profile was created and qualified for a segment in Real-Time Profile. You also verified that the profile existed at the Edge, confirmed that the event was stored in the Data Lake, and observed that the profile had not yet appeared in the Profile Snapshot dataset due to its scheduled batch update process.

Through these steps, you demonstrated how events move through the Edge, Real-Time Profile, and Data Lake layers of Adobe Experience Platform.
