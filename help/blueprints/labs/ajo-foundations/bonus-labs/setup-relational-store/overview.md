# Learning Objectives

In this exercise, we will setup the Relational schema+dataset, load data, verify them and work with Read audience in conjunction with the Relational schema. What should you walk away with after taking this Lab?

- Setting up Relational schema+dataset using DDL and load CSV data
- Load CSV data, verify the loaded data in datalake as well as in the relational store
- Create Campaign Target Dimension
- Use the Relational schema with a Read audience activity in a Campaign and test
